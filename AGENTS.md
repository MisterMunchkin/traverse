# Traverse maintained package

Keep the installed surface bounded to installation, managed model setup, doctor, repository source-inventory lifecycle and the internal agent-device runner/driving checkpoint. Live native driving validation remains pending. Preserve graph/author/acceptance contracts, explicit hash trust, uncertainty and direct-exec process ownership. The reference parser, shared AST helpers, choice transport and process supervisor have one implementation here; lab consumers may import product modules, never the reverse. Runner lifecycle is separate from actions offered to models; create/delete are unsupported capabilities.

Runtime and sample helpers must work from this package alone: no lab-tool imports, implicit sibling discovery, Git requirement or historical artifact reads. Pin exact dependencies in this package lock. Bootstrap and structured missing-parser doctor failures must work before TypeScript is installed. Track portable project config, reviewed extractor artifacts and the stable repository graph; keep local execution trust/receipts, other generated output, prefixes, caches and dependencies ignored; never install into a real default prefix in automated tests.

Follow [CONTRIBUTING.md](CONTRIBUTING.md): install both root and Expo-example locked dependencies, then run `npm run check`. The current complete contributor gate targets macOS arm64 and Node 22.13+; `.nvmrc` pins the CI version. `npm test` runs only the serial package tests; `npm run check:package` runs the isolated archive/dev-dependency smoke. Do not overlap dependency mutation with tests. For example changes run its locked setup, typecheck, lint, snapshot tests and offline web export sequentially; no desktop/device/model/service launches. In the lab, also run affected consumer tests and the available serial integration profile; preserve missing-archive limits and old provenance assertions.

Read [Node CLI design guidance](docs/contributing/cli-design.md) before CLI work. Keep existing help, stdout/JSON, exit-code and ownership contracts without requiring an IDE or lab checkout. Use one independent reviewer for a cohesive change; preserve command, source hashes, environment, deadline/signal/exit and output receipts. Local preparation does not authorize publication, shared-service actions or native integration.
